# Pixel asset family

Reserved for independently authored, versioned pixel PNG layers, material maps,
masks, and manifests. Native assembled output is 128 × 192 in authored idle pose.
Each MVP-ready asset needs all eight facings: N, NE, E, SE, S, SW, W, NW.

No artwork or manifests are present. Detailed images must not be downscaled or
mirrored to supply missing pixel art. Publication and app asset delivery will be
configured after manifest resolution exists; this directory is not automatically
served by Vite. See `docs/ASSET_SPEC.md` for the draft contract.
