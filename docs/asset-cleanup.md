## Routine generated cleanup

```bash
pnpm assets:clean --dry-run
pnpm assets:clean
pnpm assets:clean --build-outputs
```

Cleanup removes files only within these generated locations:

- `assets/staging/` (all temporary inspections and import previews).
- The generated `placeholder-v1` folders under `assets/`, `assets/detailed/`
  and `assets/pixel/`, and `apps/studio/public/placeholder-assets/`.
- `artifacts/render-demo/`, `coverage/`, `test-results/`, `playwright-report/`
  and root `.vite/`.
- With `--build-outputs`, direct workspace packages' `dist/` folders.

It never removes `assets/source/`, `assets/references/`, dependencies or project
code/documents. Staging metadata does not protect art: authoring masters and
selected inputs must live in versioned source folders. The complete cleanup
plan is checked for symlinks before any file is deleted. A dry run reports the
same plan without modifying files. `pnpm dev` and `pnpm build` regenerate the
placeholder catalog; `pnpm reference:import` regenerates reference inspection.
